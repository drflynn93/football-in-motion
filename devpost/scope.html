The experience we’re trying to prove

A compact replay should show when the lead changed and whether late scoring happened while the game was still competitive.

What the paths mean

  • Horizontal: Offense + return yards. A custom total of net rushing, passing, and return yards; gains move right and losses move left.
  • Punt and kickoff returns count. Interception returns (IR) and opponent-fumble returns (FR) count toward the returning team total. Recoveries without a return add zero return yards.
  • Vertical: each team’s actual score.
  • The gap: the actual scoring margin.
  • Both teams begin at zero yards and zero points.

Accounting · Preserve the context

This is a custom measure, not standard total offense. Keep the categories visible so a big return does not look like offensive production. Count only the return distance, not the flight of the kick, and do not count receiving yards a second time.

The selected NFL game has verified scoring, player identities, and kick/punt return details in its official gamebook. It has no interceptions or opponent-fumble recoveries, so IR/FR segments will not appear in this real replay.
